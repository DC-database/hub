IBA 17.0.0 patch 21 — glass pop-ups, Dashboard task buttons, new clock
=====================================================================
What changed
- Glass (see-through, no blur behind): Add New Job Entry, inventory New
  Transaction (Transfer / Restock / Return / Usage), Dashboard "Forward task
  details".
- Dashboard task cards: when the task is yours, a "Do it here" row with the
  same buttons as the Now brief (SRV Done, Process, Approve / Reject, Close
  out, Print) and "Active Task" to open it there.
- Assistant: "In the company" is one table with a header (PO, With, Vendor ·
  invoice · status, Age, Files). New skill chips: PO report, Approvals
  waiting, Find colleague, Find transfer, Add new job, Print basket (each
  shown only to users who may use it).
- Clock (top left): rounded-square watch face by default; click it to pick
  Square, Digital or Round (kept per browser). Time shown above the date.
- Flip cover screen (Z Flip 7 / 8): its own background photo (default
  office2.jpg; Settings > Backgrounds > "Phone · Flip cover screen").
  Fold / Duo keep the normal phone photos.
