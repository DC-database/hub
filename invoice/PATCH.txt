18.0.0 patch 2 (12-Nov-2026)
- Material Stock "All" (and every long list) froze when scrolling. Cause was the list-fit code (js/iba-1705-tblfit.js), not the rain / thunder / video background (tested: switching those off changed nothing):
  1) it wrote the list height again every 0.9 s, so the browser re-measured the whole table each time; now only when the space really changes;
  2) the row fade under the column header (a mask on the rows) made the browser repaint the whole table on every scroll step. Removed: the column header is now strongly frosted + darker, so rows under it cannot be read.
  Test with 1500 rows: one scroll step 585 ms -> 40 ms.
