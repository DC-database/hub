18.0.0 patch 129 (23-Nov-2026)
  Find LPO fix (martin): "Re-read folder" said "No folder was picked" on a PC where only "Other way to pick"
  works. The way the folder was picked was forgotten after closing Find LPO, so Re-read tried the green picker
  (which Chrome refuses there). Now it remembers: Re-read opens the same folder chooser that worked. And when
  a folder message says "use Other way to pick", the button is right there in the message.
  Material Stock much faster to scroll (martin: slow even on a good PC). Cause: the gold hover bar was moved
  by script on EVERY row the mouse passed while scrolling, and each move made the whole page recalculate its
  style (~0.1 s per row). Now hover is plain CSS (no script), the opened row keeps a gold edge. Measured in
  a test: about 110 ms per scroll step before, about 20-25 ms after (4-5x faster). Table restyled simple and
  clean: solid header, thin lines, gold monospace Product ID, teal family pill, small quiet buttons, red only on
  Delete; no shadows/blur/animations on rows. css/iba-1729-ms.css (new).
  Files: js/iba-1800-lpo.js, js/materialStock.js, css/iba-1729-ms.css (new), index.html, PATCH.txt

18.0.0 patch 2 (12-Nov-2026)
- Material Stock "All" (and every long list) froze when scrolling. Cause was the list-fit code (js/iba-1705-tblfit.js), not the rain / thunder / video background (tested: switching those off changed nothing):
  1) it wrote the list height again every 0.9 s, so the browser re-measured the whole table each time; now only when the space really changes;
  2) the row fade under the column header (a mask on the rows) made the browser repaint the whole table on every scroll step. Removed: the column header is now strongly frosted + darker, so rows under it cannot be read.
  Test with 1500 rows: one scroll step 585 ms -> 40 ms.
