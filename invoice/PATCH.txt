IBA 17.0.1 — everything since 17.0.0 patch 21
=====================================================================
Version: app.js (APP_VERSION), index.html (IBA_SYSTEM_VERSION) and
version.json all say 17.0.1, so the version check tells each browser to
load the new files.

What changed (patches 22 - 34)
- Print basket: Super Admin only.
- Clock face: only the Super Admin can pick it; the choice is saved for
  everyone.
- Access check window (Super Admin): who can open which page / button.
- White row highlight on mouse-over in tables fixed (dark theme).
- IM Financial Report (Epicore) link: Super Admin + Finance / Accounts /
  Accounting / QS only (CEO / COO removed).
- Summary Note print redesigned: bigger text, full bill description, full
  A4 portrait width, navy column header, clear borders, "Managing
  Director" signature, Previous / Current note names in the page footer.
- Add to Batch: leave the PO numbers empty and pick a status (e.g. CEO
  Approval) to take every invoice in that status (up to 100 at a time).
