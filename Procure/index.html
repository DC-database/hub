Catalog source & Firebase import

GitHub Item.csv is read-only. Import those rows (or your Excel file) into Firebase to edit, correct, or delete them. After import, matching Part Codes use the Firebase record so search does not show duplicates. To update existing records, set conflict mode to Overwrite — it matches by Part Code and replaces Series, Description, Group, Class, and Activity fields.

Catalog stats will appear after the catalog loads.
Required: Part Code. On match, these are replaced from the file: Series, Description, UOM, Group Code, Group Name, Class Code, Class Name, Activity Code, Activity Name.
